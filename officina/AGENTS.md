# Vito — Officina e Camper
App statica locale in italiano (HTML + moduli JS, nessuna build). Prima di lavorare leggi `docs/CONSEGNA.md` e `docs/STATO.md`.
- Avvio: `python3 -m http.server 8642` · Prove: `npm test`
- Dato sconosciuto = `null`, mai 0. Niente valori tecnici (coppie, sezioni, fusibili, portate) senza fonte del costruttore.
- Nuovo file JS → aggiungilo a `FILES` in `sw.js` e cambia `VERSIONE`.
- Aggiorna `docs/STATO.md` a fine sessione.
