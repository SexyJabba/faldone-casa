# INF-09.01 · Glossario A-L

**Perimetro:** Riferimento operativo per glossario a-l. Parametri e procedura da confrontare con gli apparati reali.

| Termine | Significato nel manuale |
| --- | --- |
| ACL | Permessi su file oppure regole di accesso; il contesto indica quale. |
| ARC | Cache RAM di ZFS: migliora letture, non sostituisce una copia del dato. |
| Backup | Copia recuperabile con procedura e componenti necessari; distinta da ridondanza e sync. |
| Bind mount | Percorso dell’host reso disponibile a un container; non incluso automaticamente nel suo backup. |
| Bridge | Collegamento di rete virtuale fra NIC/VM e rete del nodo. |
| Codec | Formato di codifica del video o audio; decoder ed encoder hanno capacità distinte. |
| Container / CT | Ambiente Linux che condivide il kernel host, con sistema e limiti propri. |
| Dataset | Unità ZFS con proprietà, quota e snapshot; può avere figli. |
| DHCP | Assegna parametri di rete al client; prenotazione lega l’indirizzo all’identità. |
| Direct play | Riproduzione del file senza ricodificarne il contenuto. |
| DNS | Traduce nomi in indirizzi; non autorizza l’accesso al servizio. |
| ECC | Memoria con capacità di rilevare/correggere errori secondo piattaforma; non un backup. |
| EDID | Informazioni display lette dalla sorgente per modalità video supportate. |
| HBA | Controller che presenta i dischi all’host; modalità IT nel progetto M2. |
| HEVC / H.264 | Codec video; HEVC Main10 serve per specifici profili a 10 bit. |
| IOMMU / VT-d | Isolamento e assegnazione dispositivi per passthrough; gruppi e reset si verificano. |
| LAN / localhost | Rete locale / solo il sistema stesso; una porta loopback non è un ingresso LAN. |
