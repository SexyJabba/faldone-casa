# INF-09.02 · Glossario M-Z

**Perimetro:** Riferimento operativo per glossario m-z. Parametri e procedura da confrontare con gli apparati reali.

| Termine | Significato nel manuale |
| --- | --- |
| mDNS | Discovery locale multicast, normalmente limitata al segmento. |
| MoE | Modello a esperti: parametri attivi e pesi residenti sono quantità diverse. |
| MQTT | Messaggistica fra dispositivi e servizi; broker e topic hanno autorizzazioni. |
| NAT / CGNAT | Traduzione indirizzi / traduzione del gestore, con effetti sull’ingresso diretto. |
| NVR | Backend che registra e gestisce video; diverso dal viewer. |
| Passthrough | Assegnazione di un dispositivo a una VM; PCIe e USB hanno requisiti differenti. |
| PoE | Alimentazione via Ethernet; potenza e standard di porta e dispositivo compatibili. |
| PVID / tag | Rete assegnata ai frame non taggati / identificativo VLAN nel frame. |
| QDevice / quorum | Arbitro aggiuntivo / maggioranza di voti necessaria al cluster. |
| RAG | Ricerca di fonti e uso degli estratti per generare una risposta documentata. |
| RAIDZ2 / resilver | Ridondanza ZFS a doppia parità / ricostruzione dei dati sul disco. |
| RPO / RTO | Perdita temporale tollerata / tempo di recupero richiesto o misurato. |
| Snapshot | Stato precedente sullo stesso storage; sopravvive finché quel supporto e quei blocchi esistono. |
| Subnet router | Nodo VPN che annuncia una rete e inoltra il traffico autorizzato. |
| Transcodifica | Conversione di un flusso per il client; può consumare molte risorse. |
| USB over IP | Esporta una periferica al sistema remoto; un proprietario alla volta. |
| VLAN | Segmento logico di rete; il firewall regola i passaggi fra segmenti. |
| VM / VRAM | Macchina virtuale / memoria della GPU, distinta dalla RAM del sistema. |
| Zigbee | Rete radio locale con coordinatore, router e dispositivi terminali. |

| Termine | Uso nel faldone |
| --- | --- |
| SOP | Procedura ricorrente; descrive attività ordinarie e condizioni di esecuzione. |
| MOP | Procedura di un intervento specifico: passi, attesi, punti di arresto e ritorno. |
| EOP | Procedura di risposta a un evento anomalo o emergenza. |
| Tagliando | Finestra di controllo, manutenzione e registrazione degli esiti. |
| S01 | Atlante descrittivo del faldone, pubblicazione riemessa al tagliando annuale. |
