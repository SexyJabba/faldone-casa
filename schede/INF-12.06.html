INF-12.06 Nextcloud: consegna file

Titolo d'archivio: Nextcloud: consegna file

In breve Chi deve consegnarti un file può caricarlo senza poter leggere il resto.
  • Il percorso di consegna permette l'upload senza lettura generale. Account, link e scadenza delimitano i destinatari.
  • Gli allegati arrivano in un dataset dedicato.
  • La consegna non dà accesso ai dati degli altri appartamenti né ai repository di backup.
