In breve Si può usare la TV senza altri apparecchi per Jellyfin. Per Moonlight spesso serve un box esterno.
Sistema TVCosa aspettarsi
Android TV / Google TVMoonlight e Jellyfin Android TV possibili; USB host e server USB dipendono dal modello, non dall'OS.
webOS / TizenJellyfin ha client ufficiali. Per Moonlight esistono progetti comunitari: versioni e manutenzione seguono il progetto.
Altri sistemi chiusiSi usano le app disponibili; il browser è spesso limitato. Se manca un Moonlight affidabile, si aggiunge un endpoint esterno.

Limiti che contano davvero

  • La porta Ethernet di alcune TV è a 100 Mb/s: può bastare per un uso moderato, non per file 4K a bitrate alto più altri flussi.
  • Telecomando, modalità gioco, ritardo del pannello e controlli audio fanno parte della postazione. Disattivare le elaborazioni video incompatibili con la bassa latenza.
  • Le USB di una TV possono servire solo per file o accessori del produttore, non implicano un server USB over IP.
  • Un aggiornamento del televisore può rompere una compatibilità comunitaria. Conservare versione app/firmware e una via alternativa ai servizi.

Percorso operativo

  1. Provare prima Jellyfin nativo con file e sottotitoli abituali; verificare che il server faccia Direct Play quando possibile.
  2. Provare Moonlight solo dopo aver identificato app, procedura supportata e controller. Misurare input e stabilità, non solo la comparsa del desktop.
  3. Se l'esperienza è incompleta, tenere la TV come display e usare HDMI da box o mini PC. Un ponte USB separato copre le periferiche.
